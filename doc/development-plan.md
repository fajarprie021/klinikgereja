# Development Plan Klinik Gereja

## Phase 1 - Foundation

Target: - Setup Laravel - Database - Authentication - Role permission

## Phase 2 - Clinical Workflow

Membangun: - Pasien - Dokter - Jadwal - Appointment - Rekam medis

## Phase 3 - Financial

Membangun: - Transaksi - Subsidi - Dana gereja - Laporan

## Phase 4 - Mobile

Flutter: - Login pasien - Booking - Antrean - Riwayat medis

## Rule Development

Setiap fitur harus menjawab: 1. Siapa pengguna fitur ini? 2. Masalah apa
yang diselesaikan? 3. Database apa yang digunakan? 4. Apakah masuk MVP?

Jika tidak memenuhi, fitur ditunda.
