# Sistem Informasi Klinik Gereja

## Deskripsi

Sistem Informasi Klinik Gereja adalah aplikasi pelayanan kesehatan
berbasis web dan mobile untuk mengelola pelayanan kesehatan jemaat dan
masyarakat umum.

Sistem mendukung: - Registrasi pasien - Pemeriksaan dokter - Rekam
medis - Antrean pelayanan - Subsidi biaya kesehatan - Laporan pelayanan
gereja

## Tujuan Sistem

1.  Mempermudah administrasi klinik gereja.
2.  Menyediakan rekam medis pasien digital.
3.  Mengelola subsidi kesehatan secara transparan.
4.  Memberikan laporan pelayanan kepada pengurus gereja.

## Pengguna Sistem

### Super Admin Gereja

-   Mengelola seluruh sistem.
-   Mengelola user.
-   Melihat laporan.

### Admin Klinik

-   Registrasi pasien.
-   Mengatur jadwal dokter.
-   Mengelola antrean.
-   Mengelola transaksi.

### Dokter

-   Melakukan pemeriksaan.
-   Membuat diagnosis.
-   Mengisi rekam medis.

### Perawat

-   Pemeriksaan awal.
-   Input tanda vital.

### Bendahara Gereja

-   Mengelola subsidi.
-   Melihat laporan dana.

### Pasien

-   Registrasi.
-   Booking pemeriksaan.
-   Melihat riwayat kesehatan.

2.  Setiap tabel database harus memiliki fungsi bisnis.
3.  Hindari duplikasi data.
4.  Semua transaksi penting memiliki histori.
